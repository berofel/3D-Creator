◆ Berofel 3D CreateEditor modular 3D • criaturas, armas e ferramentas

CRIATURA

Arraste para girar a câmera; use pinça para zoom. Toque numa peça para selecioná-la.

ADICIONAR PEÇA

OFICINA DE ARMAS

Monte equipamentos low-poly por componentes. Selecione cada peça na hierarquia para mover, girar, escalar ou mudar a cor. O modelo pode ser exportado em JSON ou GLB.

Dica: use a hierarquia para escolher uma peça e os controles de transformação para ajustar a forma. As peças permanecem separadas para facilitar variantes.

HIERARQUIA

MANIPULAÇÃO 3D

Selecione uma peça e escolha como quer manipulá-la. Arraste as setas coloridas no modelo; durante o arrasto, a câmera fica travada.

Na vista frontal, o eixo X move para os lados e Y para cima/baixo. O eixo Z fica oculto para facilitar ajustes em 2D.

TRANSFORMAR PEÇA

ESQUELETO E PELE

O esqueleto é a estrutura articulada; a pele é uma camada de volumes suaves por cima. Alterne as visualizações durante a construção.

Pele visível; esqueleto oculto.

RIG E ANIMAÇÃO

Ciclos com flexão das juntas, transferência de peso e movimentos secundários. A anatomia ainda é uma aproximação procedural, não simulação muscular física.

Rig pronto — escolha uma animação.

ARQUIVOS

JSON salva as peças e suas transformações. GLB gera um modelo 3D para baixar e importar em outros programas.

ANIMAÇÃO — COLHEITA DE PINHEIRO

Demonstração procedural leve: jogador, machado e pinheiro na mesma cena. Reproduza a sequência ou teste cada impacto.

Crie a demonstração para visualizar a sequência.

O modelo é gerado no editor com cilindros, galhos e copas onduladas. Não usa modelo baixado nem simulação física pesada.
