# PixelFX — third-party attribution

Berofel 3D Create integrates PixelFX as an on-demand browser module.

- Upstream project: https://github.com/patch-gg/pixelfx
- Gallery: https://patch-gg.github.io/pixelfx/
- License: MIT
- Copyright notices: Patch and Hugo Duprez (2026)

The PixelFX source is loaded from esm.sh at runtime; it is not vendored into this repository. The upstream MIT license and notices remain applicable to the library and its effects. The PixelFX gallery font has a separate notice and is not used by this integration.

Integration scope: curated effect browser, live 2D preview, and Three.js sprite attachment to the currently selected object. Full bone-socket binding and export baking are not part of this initial integration.
